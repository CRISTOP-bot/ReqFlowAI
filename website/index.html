Un espacio de trabajo para APIs

Prueba y organiza tus flujos API con claridad.

ReqFlow AI es una aplicación de escritorio en desarrollo, construida con C++20 y Qt 6. Está pensada para crear peticiones HTTP, guardar proyectos locales y explorar flujos de API.

Hecho para el trabajo cotidiano con APIs

Un escritorio local-first que reúne herramientas prácticas para preparar solicitudes, conservar el contexto del proyecto y recorrer automatizaciones sin perder de vista el estado real de cada función.

Cliente HTTP

Configura métodos, URL, parámetros, cabeceras y cuerpo para tus solicitudes.

Interfaz de escritorio

Proyectos e historial

Guarda localmente peticiones, entornos, historial y suites con SQLite.

Almacenamiento local

Flujos de API

El proyecto incluye un editor visual y un motor de flujos; sus límites siguen en desarrollo.

En desarrollo

Importación OpenAPI

Importa un subconjunto de OpenAPI 3.x en JSON o YAML; las referencias admitidas son limitadas.

Soporte parcial

Suites y respuestas

Incluye aserciones y herramientas para inspeccionar respuestas HTTP y JSON.
