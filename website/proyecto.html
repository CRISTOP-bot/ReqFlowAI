Acerca del proyecto

Una aplicación de escritorio local-first para APIs.

ReqFlow AI se desarrolla en C++20 y Qt 6. El objetivo es ofrecer un espacio local para trabajar con peticiones HTTP, datos de proyecto y flujos de API, con evolución gradual del backend.
